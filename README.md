# Counter Stock

店舗における景品在庫管理業務の効率化を目的として開発したWebアプリケーションです。

私自身の店舗運営経験をもとに、現場で発生していた在庫管理・棚卸・発注判断の課題を解決するために設計・開発しました。

---

## アプリ概要

Counter Stockは、景品の入出庫管理から棚卸、原価率分析、出庫予測までを一元管理できる在庫管理システムです。

従来はExcelや紙で管理されていた業務をシステム化し、作業負荷の軽減とデータ活用を実現することを目的としています。

---

## 主な機能

### マスタ管理

* 商品登録
* カテゴリ登録
* グループ登録
* 店舗登録

### 在庫管理

* 入庫登録
* 出庫登録
* 在庫数管理
* 在庫履歴管理

### 棚卸機能

* 棚卸実施
* 棚卸結果確認
* 棚卸履歴管理
* 差異確認

### 分析機能

* 原価率分析
* 出庫予測分析
* グループ別集計

### データ管理

* CSVインポート機能
* 一覧表示機能
* フィルタリング機能

## 工夫した点

### 現場業務をベースに設計

実際の店舗運営経験から業務フローを洗い出し、現場で利用しやすい画面構成を意識しました。

### データ活用を意識した分析機能

単なる在庫管理ではなく、出庫予測や原価率分析機能を実装し、発注判断や利益管理に活用できるようにしました。

### 棚卸業務の効率化

棚卸専用画面を用意し、棚卸結果や差異確認を簡単に行えるよう設計しました。

### 開発環境の統一

Dockerを利用し、環境差異なく実行できる構成としています。
